## Token-Efficiency Protocol (ALWAYS FOLLOW)
1. **NEVER read large `.js` files in full** (`curriculum.js`, `science_curriculum.js`, `exam_expansion.js`, `shs_handouts_expansion.js`, `everylingo_*.js`, `primer_*.js`, `app.js`, `memorize.js`, `styles.css`).
2. **Read `primer_manifest.json` FIRST** (~20 KB, auto-regenerated by `node verify_and_bundle.mjs`). It gives exact counts, file sizes/line counts, key function line anchors, all World IDs, Node IDs, Playground IDs, Gym Mode IDs, and Tutor Presets in ONE tiny read.
3. **Locate & slice surgically**: Use `grep -n` to find exact line numbers, then `read_file` with tight `StartLine`/`EndLine` windows (40–100 lines) and `edit_file` for minimal diffs.
4. **Adding new content?** Activate the workspace skill `.agents/skills/everylingo-maintainer/SKILL.md` for copy-paste schemas so you never need to read existing curriculum files as examples.

## Hard Invariants (Checked Automatically by `verify_and_bundle.mjs`)
- **Zero `:root` blocks** in `styles.css` and **zero legacy neon hexes** (`#58cc02`, `#1cb0f6`, `#ff9600`, `#ce82ff`, `#ff4b4b`, `#ffd900`, `#ffc800`).
- **Every new node** needs: unique `id`, valid `worldId`, registered `visualizerId`, 3+ `microSteps`, 5 questions (`mc` has 4 unique options containing `answer`), a `>= 4`-variant procedural generator registered via `DATA.registerProceduralMap(...)`, worked example in `LATEX.registerWorkedExamples`, and an entry in `TUTOR.DEPENDENCY_GRAPH`.
- **Every trap** MUST include `quiz.explanation`. Never print literal `undefined` (`escapeHtml` guards `null`/`undefined`).
- **Filipino KWF Malumi rule**: Grave accent (`paiwa`) ALWAYS sits on the **final vowel** (`batà`, `luhà`, `punò`, `tubò`).
- **Never write literal closing script tags** inside `.js` files (breaks standalone HTML bundling).
- **Always finish edits by running**: `node /home/sibug/Math/verify_and_bundle.mjs` (verifies all invariants, stamps `sw.js`, refreshes `primer_manifest.json`, and updates `primer.standalone.html`).
